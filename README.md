# Ayiti Digital Studio — Portfolio

Site vitrine : https://ayiti-digital-studio.vercel.app

## Modifier les informations
Tout se trouve en haut de `app/page.tsx` (bloc CONFIGURATION) :
- `numeroWhatsapp`, `numeroAffiche`, `email`
- `services` (3 cartes)
- `projets` : collez le lien d'un projet terminé dans `lien`
- `etapes` (section « Comment je travaille »)

Couleurs et animations : `app/globals.css`. Titre, description et aperçu WhatsApp : `app/layout.tsx` et `app/opengraph-image.jpg`.

## Commandes
```bash
npm run dev     # voir le site sur http://localhost:3000
npm run build   # vérifier qu'il n'y a pas d'erreur
```
